# PALLAVI.OS — Portfolio

React + Vite desktop-style portfolio for Pallavi Sharma.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Included functionality

- Animated PALLAVI.OS boot screen with working Enter button
- Live time and date on the desktop taskbar
- Start menu with all portfolio sections
- Working About, Skills, Projects, Experience, Achievements, Resume, Contact and Terminal windows
- Close, minimize and maximize/restore controls
- Window focus / bring-to-front behavior
- Taskbar app buttons restore/focus open windows
- Terminal commands for opening sections
- GitHub repository loading with graceful fallback
- Resume preview and download
- Restart PALLAVI.OS action that returns to the boot screen
- Responsive desktop/tablet/mobile layouts
- Existing source modules and assets retained
